Send a one-way notification to the user's Telegram chat.

Use this tool when you want to notify the user about:
- A task that has been completed successfully (use severity `success`).
- An error that occurred and requires attention (use severity `error`).
- A warning about something unexpected (use severity `warning`).
- General information the user asked to be notified about (use severity `info`).

Do not use this tool for every minor step; reserve it for meaningful milestones or failures.
