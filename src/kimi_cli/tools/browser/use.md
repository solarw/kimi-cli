Delegate a complex browser task to browser_use Agent powered by the same Kimi API.

This tool launches an autonomous browser agent that uses your Kimi API credentials to perform multi-step web tasks (search, fill forms, extract data, etc.). It handles navigation, clicking, typing, and decision-making automatically.

Use this for complex tasks that would require many manual steps. For simple tasks (single page load, one click), prefer the individual Browser* tools.
